# Low-Level Design

The complete LLD is split into focused documents:

- [Database Schema](database-schema.md): JPA mapping, columns, constraints, indexes, and repository operations.
- [API Design](api-design.md): REST contracts, examples, statuses, and error responses.
- [Class Design](class-design.md): responsibilities, layering, Redis abstraction, and patterns actually used.
- [Sequence Diagrams](sequence-diagrams.md): create, redirect hit/miss, statistics, delete, and expiry flows in Mermaid.
- [Design Decisions](design-decisions.md): code generation, aliases, expiry, click persistence, invalidation, and consistency boundaries.
